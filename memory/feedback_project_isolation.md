Never read, search, or reference the contents of another OZ project unless Oussama explicitly says to. Projects are isolated by his decision, not by accident. This includes cross-project "helpful" checks like looking for overlapping work, reusable patterns, or duplicate effort — do not do it uninvited. The same applies to broad filesystem searches outside the active project directory.

**Why:** He decides what is related to what. Cross-referencing projects on my own initiative imports context he deliberately kept separate and reframes his request as a different project's problem. Stated directly on 2026-08-17 after I checked TrackerPlatform and SandboxPiano while working in YE: "these are two different projects — you should never check another project content unless I tell you so. my decision."

**How to apply:** Stay inside the active project directory. If work in one project genuinely seems to overlap another, say what I would check and why, and ask permission — do not check first and report after. Arguments should stand on the active project's own content. Related: [[feedback-progress-tracker]].
